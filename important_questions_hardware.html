I Unit - I: Hardware Architecture

Most Critical

Q1. Define Motherboard. Explain the architecture and key differences between AT, ATX, and BTX motherboards.

Definition: The Motherboard (also known as the System Board or Mainboard) is the main printed circuit board (PCB) in a computer. It serves as the central communications backbone, holding crucial components like the CPU and RAM, and providing connectors for other peripherals.

Form Factor Comparison:

Feature AT (Advanced Technology) ATX (Advanced Technology eXtended) BTX (Balanced Technology eXtended)
Era Old Legacy (1980s). Obsolete. Current Standard (1995-Present). Failed Standard (2004).
Power Switch Physical switch connected to Mains. No Software shutdown. "Soft Power". OS can shut down system. Supports Sleep/Wake. Soft Power.
Design Focus None. Cluttered cables blocked airflow. User-friendly. I/O ports integrated. Better airflow. Thermal Airflow. Components aligned in a "Tunnel" for cooling.
Connectors Split Power P8/P9 (Risk of error). Single 20/24-pin Keyed connector. 24-pin.
High Priority

Q3. What is RAM? Differentiate between SRAM, DRAM, and SDRAM.

RAM (Random Access Memory): It is the computer's volatile main memory used to store data and instructions currently in use by the CPU.

  • SRAM (Static RAM):
    Uses flip-flop circuits (transistors) to hold data. It is Fast but expensive and takes up more space. It does not need refreshing.
    Use: CPU Cache (L1, L2, L3).
  • DRAM (Dynamic RAM):
    Uses capacitors to hold data. Capacitors leak charge, so it must be "Refreshed" thousands of times per second. It is slower but cheaper and denser.
    Use: Main System RAM.
  • SDRAM (Synchronous DRAM):
    A type of DRAM that Synchronizes itself with the CPU's system clock. This eliminates wait states and improves efficiency. Modern DDR RAM is a type of SDRAM.
Sure Topic

Q4. Differentiate between PATA (IDE) and SATA interfaces.

The transition from PATA to SATA is the most critical storage topic.

Feature PATA (Parallel ATA / IDE) SATA (Serial ATA)
Data Transfer Parallel (Multiple bits at once). High interference. Serial (1 bit at a time). Fast & Efficient.
Cable Wide, Gray Ribbon (40/80 pin). Blocks Airflow. Narrow, Red Cable (7 pin). Good Airflow.
Speed Max 133 MB/s. Up to 6 Gbps (SATA III).
Config Master/Slave Jumpers required. Point-to-Point (No Jumpers).
Essential

Q5. Explain the working of a UPS and its types.

UPS (Uninterruptible Power Supply): A device that provides battery backup when electrical power fails.

Block Diagram Concept:
Main AC Input -> [Rectifier (AC to DC)] -> [Battery] -> [Inverter (DC to AC)] -> Computer Load
  • Offline (Standby): Computer runs on wall power. When power fails, it switches to battery (5ms delay). Good for Home PCs.
  • Line-Interactive: Contains an AVR (Automatic Voltage Regulator) to fix low/high voltage without using the battery. Better protection.
  • Online (Double Conversion): Computer always runs on battery power converted by the inverter. Zero transfer time. Best for Servers.

Procedure

Q8. Step-by-step procedure for Windows Installation.

  1. Prepare Media: Download Windows ISO and create a bootable USB using a tool (like Rufus or Media Creation Tool).
  2. BIOS Setup: Insert USB, restart PC, enter BIOS (F2/Del), and set USB as Primary Boot Device.
  3. Boot: Save and Exit. The system boots from USB. Select Language and click "Install Now".
  4. License: Enter Product Key (or skip) and accept License Terms.
  5. Installation Type: Select "Custom: Install Windows only (Advanced)".
  6. Partitioning:
    • Select the unallocated drive.
    • Click "New" to create partition.
    • Select proper drive and click "Next".
  7. Copying: Windows will copy files and restart automatically.
  8. OOBE (Out Of Box Experience): Set up Username, Password, and Privacy settings.
Technical

Q9. What is DISKPART? List commands to create a partition.

DISKPART is a command-line utility in Windows for disk management. It allows scripts and handles partitions that GUI cannot.

// Start Tool
> diskpart

// View and Select Drive
> list disk
> select disk 0 (Selects the first physical drive)

// Clean Steps
> clean (Wipes all data/partitions)

// Creation
> create partition primary
> select partition 1
> active (Marks it as bootable)

// Formatting
> format fs=ntfs quick
> assign letter=C
> exit

2. Key Definitions

  • Device Driver: Software that allows the OS to communicate with specific hardware (e.g., Audio Driver).
  • Cache Memory: Extremely fast memory inside the CPU (SRAM) stores frequently used data to speed up processing.
  • Firmware: Permanent software programmed into a read-only memory (ROM) (e.g., BIOS).
  • CMOS Battery: A coin cell battery on the motherboard that powers the BIOS/RTC to save Date & Time when PC is off.
