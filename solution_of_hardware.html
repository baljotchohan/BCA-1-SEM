I

Hardware Architecture & Components

1. The Motherboard & Form Factors

The Motherboard (System Board) is the backbone of the PC. The syllabus focuses on Form Factors (Size/Shape/Layout).

Legacy: AT (Advanced Technology)
  • Era: Mid-80s (IBM). Obsolute now.
  • Size: Large (12" x 13.8").
  • Power Switch: Directly connected to mains voltage (No software shutdown).
  • Flaws: "Cable Nest" (ribbon cables blocking airflow), manual power switch, connector confusion (P8/P9).
Standard: ATX (Advanced Tech eXtended)
  • Era: 1995 (Intel) to Present. Dominate standard.
  • Key Feature: "Soft Power" (OS can shut down system).
  • Layout: Rotated 90 degrees for better cooling. CPU near PSU fan.
  • Connectors: Integrated I/O panel (less clutter), keyed power plug (cannot insert backwards).
Note on BTX: Introduced in 2004 to solve heat issues with a "Traffic Tunnel" airflow design. It failed commercially as CPUs became more efficient, making the radical redesign unnecessary.

2. Peripheral Interfaces (Ports)

Feature Serial Port (COM) Parallel Port (LPT)
Transmission Sequential (1 bit at a time). Simultaneous (8 bits/1 byte at a time).
Connector DE-9 (9-pin Male) or DB-25. DB-25 (25-pin Female).
Key Usage Modems, Mice, Industrial Routers. Best for Long Distance. Printers (LPT = Line Print Terminal). Best for Short Distance.
Speed Slower, but reliable over distance. Faster (Historically), but suffers crosstalk.

3. Data Storage (PATA vs SATA)

The evolution of Hard Disk Interfaces is a guaranteed exam topic.

PATA (Parallel ATA) / IDE

  • Uses wide, flat 40/80 pin ribbon cables (obstructs airflow).
  • Configuration: Master/Slave jumpers required (2 drives per cable).
  • Speed limit: 133 MB/s. No hot-swapping.

SATA (Serial ATA) - The Modern Standard

  • Uses thin 7-pin cables (better airflow).
  • Configuration: Point-to-Point (1 drive per port, no jumpers).
  • Speed: Up to 6 Gbps (SATA III). Supports Hot-Swapping.
II

Software, Maintenance & Security

4. The Boot Process & BIOS

BIOS (Basic Input/Output System): Firmware on the motherboard that initializes hardware. It runs the POST (Power-On Self-Test) to check RAM, CPU, and Video before loading the OS.

🥶 Cold Booting

Starting a computer from a completely off state. Checks all hardware (POST). High stress on components.

🔥 Warm Booting

Restarting a computer that is already on (Ctrl+Alt+Del). Skips full memory check. Faster.

5. Windows Installation & DISKPART

IMPORTANT: You must write steps in numbered format for the exam.

  1. Create Bootable Media (USB/DVD).
  2. Enter BIOS and set Boot Priority to USB.
  3. Boot system. Select Language -> "Install Now".
  4. Select "Custom: Install Windows only (Advanced)".
  5. Partitioning: Delete old partitions -> Select Unallocated Space -> New.
  6. Windows copies files and restarts multiple times.
  7. OOBE: Create User Account, Set Privacy settings.

6. Security: Antivirus vs Firewall

Antivirus

Protects the Internal System (Files/RAM). Scans for signatures of known malware initiated by the user (downloads, USBs).

  • Norton, McAfee
  • Removes infected files

Firewall

Protects the Perimeter (Network). Acts as a gatekeeper monitoring incoming/outgoing traffic ports.

  • Hardware or Software
  • Blocks hackers/worms
